# Импорт оборудования из CSV и JSON

Раздел «Оборудование» → «Импорт из файла» (только роли admin и master).
Импорт идёт в два шага: файл сначала **проверяется** и показывается, что
произойдёт, и только после подтверждения записывается в систему. Если в файле
есть хотя бы одна ошибка, не записывается ничего.

## Формат файла

**JSON** — массив объектов (допустим и объект с ключом `equipment`, внутри
которого тот же массив):

```json
[
  {
    "inventory_number": "2101344347",
    "name": "Принтер Canon",
    "category": "Принтер",
    "status": "working",
    "room_number": "4-ка"
  }
]
```

**CSV** — первая строка с названиями колонок, разделитель `;` или `,`,
кодировка UTF-8 или Windows-1251 (то, что сохраняет русский Excel). Шаблон
можно скачать на странице импорта.

Названия ключей не зависят от регистра. Незнакомые колонки игнорируются, но
на странице проверки о них предупреждают — так видна опечатка в названии.

## Поля

| Ключ | Обязательно | Значение |
|---|---|---|
| `inventory_number` | да | Только цифры, до 20 знаков. По нему система находит оборудование |
| `accounting_number` | нет | Формат `А1-сотрудник-001`: корпус А/Б, этаж 1–5, группа (студент, преподаватель, администрация, сотрудник), три цифры. Должен быть уникальным |
| `name` | нет | 2–255 символов |
| `model`, `serial_number` | нет | До 255 символов |
| `category` | нет | Название категории, как в системе |
| `status` | нет | `working`, `in_service`, `broken`, `decommissioned` или русское название. У нового оборудования пусто = `working` |
| `room_number` | нет | Номер кабинета, как в системе |
| `room_name` | нет | Название кабинета; используется, только если кабинет создаётся |
| `operating_system` | нет | Название или slug ОС. Сохраняется для категорий с ОС (компьютер, ноутбук); для остальных — предупреждение |
| `has_warranty` | нет | `true`/`false`, `1`/`0`, `да`/`нет` |
| `warranty_end_date` | нет | `2026-12-31` или `31.12.2026`. Если указана без `has_warranty`, гарантия считается действующей. Прошедшие даты разрешены |
| `last_service_date` | нет | Та же запись даты, не позже сегодняшнего дня |
| `service_comment`, `known_issues` | нет | 5–500 символов |

Пустое значение (`""`, `null`, пустая ячейка) означает «не менять».
Очистить поле через импорт нельзя.

## Параметры загрузки

- **Оборудование уже есть** (совпал `inventory_number`): *пропустить* — запись
  не трогается, либо *обновить* — меняются только заполненные поля.
- **Создавать недостающие категории и кабинеты**: если выключено, незнакомая
  категория или кабинет — ошибка. Новый кабинет создаётся с типом «Другое»,
  новая категория — без поддержки ОС.

## Что делает импорт

- Новое оборудование с кабинетом получает запись «Первоначальное размещение»
  в истории перемещений. При обновлении со сменой кабинета пишется запись о
  перемещении.
- Уведомления о смене статуса или кабинета (как при ручном редактировании) при
  импорте не отправляются, чтобы массовая загрузка не засыпала их.
- Оборудование из корзины обновить нельзя: сначала восстановите его.
- Ограничения: файл до 5 МБ и до 2000 записей.

## Подсказки для Excel

- Колонку `inventory_number` сделайте **текстовой** до ввода данных. Иначе Excel
  обрежет ведущие нули, а длинные числа превратит в `2,10134E+09`.
- Сохранение: «Файл → Сохранить как → CSV (разделители — запятые / CSV UTF-8)».
- Даты лучше писать как `31.12.2026` или `2026-12-31`; числовые серийные даты
  Excel (например, `46022`) не поддерживаются.
