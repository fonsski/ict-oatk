# Настройка отправки почты через SMTP Gmail

Почта нужна для восстановления пароля и писем об активации учётной записи.
Отправка идёт штатным SMTP-драйвером Laravel — никаких дополнительных
пакетов и OAuth не требуется.

> **Никогда не записывайте логин и пароль в файлы репозитория.** Все
> значения задаются только в `.env`, который в git не попадает.

## Что понадобится

Gmail не пускает по обычному паролю от аккаунта. Нужен **пароль приложения**:

1. Включите в аккаунте двухфакторную аутентификацию
   (Google Account → Безопасность).
2. Откройте [Пароли приложений](https://myaccount.google.com/apppasswords).
3. Создайте пароль для приложения «Почта» — Google покажет 16 символов.
4. Этот пароль и используйте в `MAIL_PASSWORD`.

## Настройки в `.env`

```env
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=адрес@вашдомен
MAIL_PASSWORD=пароль-приложения
MAIL_FROM_ADDRESS=адрес@вашдомен
MAIL_FROM_NAME="${APP_NAME}"
```

Про шифрование: на порту 587 STARTTLS включается автоматически, отдельная
настройка не нужна. Если провайдер требует порт 465 (implicit TLS), добавьте
`MAIL_SCHEME=smtps`.

Начиная с Laravel 11 переменная `MAIL_ENCRYPTION` больше не читается — её
заменил `MAIL_SCHEME`.

После правки `.env`:

```bash
php artisan config:clear   # локально
php artisan config:cache   # на боевом сервере
```

## Проверка

```bash
php artisan tinker
```

```php
Mail::raw('Проверка связи', fn ($m) => $m->to('куда@отправить')->subject('Тест'));
```

Письмо уходит в очередь, поэтому на боевом сервере должен работать обработчик
(`ict-help-queue.service`, см. `deploy/README.md`). Локально можно выполнить
разово: `php artisan queue:work --once`.

## Если письма не уходят

| Симптом в `storage/logs/laravel.log`        | Причина                                      |
|---------------------------------------------|----------------------------------------------|
| `535-5.7.8 Username and Password not accepted` | Используется обычный пароль вместо пароля приложения |
| `Connection could not be established`        | Закрыт исходящий порт 587 на файрволе виртуалки |
| Писем нет, ошибок тоже                       | Не запущен обработчик очереди                |

## Локальная разработка

В Laravel Sail поднят Mailpit — письма никуда не уходят, а открываются в
браузере на <http://localhost:8025>:

```env
MAIL_MAILER=smtp
MAIL_HOST=mailpit
MAIL_PORT=1025
MAIL_USERNAME=null
MAIL_PASSWORD=null
```
